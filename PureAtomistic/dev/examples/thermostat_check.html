Canonical sampling with the Bussi thermostat ​

500 Cu atoms with MACE-MPA-0 and velocity Verlet, coupled to the stochastic velocity-rescaling thermostat of Bussi, Donadio and Parrinello at 1200 K for 2 ps. In the canonical ensemble the kinetic energy K of the N_f = 3N − 3 degrees of freedom is Gamma-distributed with shape N_f/2 and scale k_B T, whatever the potential, so the kinetic temperature 2K/(N_f k_B) has mean T and variance 2T²/N_f. The thermostat is meant to reproduce that distribution; this run checks it on the real potential.

This page does not run the dynamics. It reads bench/results/md_thermostat_check.json, which holds the kinetic temperature of every step together with the commit, the date and the settings, and plots it. The first half of the run is discarded and the second half (1 to 2 ps) is analyzed. The crystal starts at the lattice sites with 1200 K velocities, so it equilibrates while the thermostat holds the kinetic temperature.

julia
using CairoMakie, JSON, Printf, PureAtomistic, Statistics
const RESULTS = joinpath(pkgdir(PureAtomistic), "bench", "results")
d = JSON.parsefile(joinpath(RESULTS, "md_thermostat_check.json"))
s, th, ob = d["settings"], d["theory"], d["observed"]
@printf(
    "commit %s, %s, Julia %s, BLAS %s on %d thread, %d atoms, dt = %g fs, tau = %g fs, seed %d\n",
    s["commit"], s["date"], s["julia"], s["blas"], s["blas_threads"], s["natoms"], s["dt_fs"], s["tau_fs"], s["seed"]
)
t, T = Float64.(d["t_fs"]), Float64.(d["temperature_K"])
half = t .> 1000
x = T[half]
commit b67cde9, 2026-11-06, Julia 1.13.3, BLAS pureblas on 1 thread, 500 atoms, dt = 2 fs, tau = 20 fs, seed 20261107

Mean and variance against theory ​

Consecutive samples (2 fs apart) are strongly correlated, so they are not independent. The error of the mean comes from the integrated autocorrelation time τ of the analyzed series, with Sokal's automatic window (M ≥ 6τ): SEM = σ √(2τ/N), with N_eff = N/(2τ) independent samples. The error of the skewness is √(6/N_eff), the large-sample value for independent Gaussian samples. z is the deviation from theory in units of that error. The variance error is a delete-one-block jackknife over 5 blocks of 100 samples (200 fs each); the blocking table below shows that this block length is too short for the mean, and the variance error was not rechecked.

Blocking analysis of the mean: the standard error of the mean against block length. A plateau means the blocks are longer than the correlation time of the temperature. There is none here: the error is still rising at 50 samples (10 blocks), so the 5 blocks of 100 samples used for the first estimate underestimate the error. The histogram is of the analyzed samples; the curve is the Gamma density of the kinetic temperature (normalized numerically on the plotted range).

julia
dof = s["dof"]
Tset = th["mean_K"]
grid = range(Tset - 5 * th["std_K"], Tset + 5 * th["std_K"]; length = 400)
logpdf = @. (dof / 2 - 1) * log(grid) - grid * dof / (2 * Tset)
pdf = exp.(logpdf .- maximum(logpdf))
pdf ./= sum(pdf) * step(grid)
fig = Figure(; size = (900, 380), fontsize = 13)
ax1 = Axis(fig[1, 1]; xlabel = "time (ps)", ylabel = "kinetic temperature (K)")
lines!(ax1, t ./ 1000, T; linewidth = 1)
hlines!(ax1, [Tset]; color = :crimson)
vlines!(ax1, [1.0]; color = :gray, linestyle = :dash)
ax2 = Axis(fig[1, 2]; xlabel = "kinetic temperature (K)", ylabel = "density")
hist!(ax2, x; normalization = :pdf, bins = 20, color = (:steelblue, 0.6), label = "$(length(x)) samples, 1 to 2 ps")
lines!(ax2, grid, pdf; color = :crimson, linewidth = 2, label = "canonical")
axislegend(ax2; position = :lt)
save("thermostat_distribution.png", fig)
