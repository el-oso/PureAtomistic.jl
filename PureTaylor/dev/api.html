Construction and read-out ​

PureTaylor.Taylor Type
julia
Taylor{N,K,M,T,L}

Truncated Taylor polynomial in N variables up to total degree K, with coefficients of type T. Only the variables in the bit mask M (bit i-1 set means variable i) carry nonzero higher-order terms. c holds c_α = (∂^α f)/α! for every multi-index α of multi_indices(Val(N), Val(K)) supported on those variables, in that order, so c[1] is the value and L == binomial(count_ones(M) + K, K). N, K and M are Ints with 1 ≤ N ≤ 63 (the mask is an Int), K ≥ 0 and 0 ≤ M < 2^N.

source
PureTaylor.variable Function

The number x + s·uᵢ, a series in uᵢ, for 1 ≤ i ≤ N. With s = x every coefficient stays of order 1 in size; derivatives undoes the scaling.

PureTaylor.derivatives Function
julia
derivatives(a, invscale)

All partial derivatives ∂^α f = α! · c_α · Π invscale_i^α_i in multi_indices(Val(N), Val(K)) order, with invscale_i = 1/s_i for the seed scales s_i; zero where α is not stored. The entries of invscale are converted to the coefficient type of a.

Each derivative is formed as c_α times the factors j·invscale_i, j = 1, …, α_i, variable by variable, so neither α!·c_α nor invscale_i^α_i has to be representable. Within one variable the factors increase in magnitude with j, so for a derivative in one variable no partial product exceeds the larger of |c_α| and the result in magnitude.

source
PureTaylor.coefficient Function
julia
coefficient(a, α)

The coefficient c_α = (∂^α f)/α! of a (in the seed variables u), or zero when α is not stored.

source
PureTaylor.substitute Function
julia
substitute(E::Taylor{N,K}, u)

Change of variables. E is a series whose N variables are increments of N quantities; u[i] is the i-th quantity as a Taylor{N2,K} over new variables, or a plain number for a quantity that does not change. At least one u[i] is a Taylor, and all of them have the same N2. The result is Σ_α c_α · Π_i (u[i] - value(u[i]))^α_i over the coefficients c_α of E, a Taylor{N2,K} over the new variables. The values of u are not used: E is taken to be expanded around them. When variable i of E was seeded with a scale s (variable(…, x, s)), it is the increment divided by s, so pass u[i] / s.

source

Arithmetic and elementary functions ​

Base.sqrt Method
julia
sqrt(a::Taylor)

The series of √a, with its value from Base's sqrt (a negative value throws DomainError). At value 0 the derivatives are singular: every coefficient but the value is NaN.

source

source
Base.:^ Method
julia
a^p

The series of aᵖ for a real (or rational) p, converted to the coefficient type of a. An integer-valued p is the integer power. Otherwise the value comes from Base's ^ (a negative value throws DomainError), and at value 0 the derivatives are singular: every coefficient but the value is NaN.

Base.:^ Method
julia
a^b
r^b

The series of aᵇ for a Taylor exponent b, as exp(b·log(a)); a real base r is converted to the coefficient type of b, and ℯ^b is exp(b). The base's value goes through log: a negative value throws DomainError, and at value 0 the result has non-finite coefficients.
