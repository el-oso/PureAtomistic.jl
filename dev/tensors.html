Tensor kernels ​

PureMLIP.Tensors is a public submodule that holds the equivariant tensor kernels of the MACE model: the channel-wise tensor product, e3nn linear maps, species-indexed linear maps and the symmetric contraction, each with its pullback. PureMLIP does not re-export its names; reach them as PureMLIP.Tensors.name, or with using PureMLIP.Tensors. The kernels' docstrings state what each computes as einsums; the spherical harmonics and tensor kernels example lists them.

Reference ​

PureMLIP.Tensors Module
julia
PureMLIP.Tensors

Equivariant tensor kernels on node and edge features: the channel-wise tensor product with sparse e3nn coupling tensors, e3nn Linear and species-indexed linear maps, and the MACE symmetric contraction, each with its vector-Jacobian product. It depends only on PureMLIP.Equivariant (for the coupling tensors) and LinearAlgebra, and holds no code that reads checkpoints, so it can be used on its own.

PureMLIP.Tensors.ChannelwiseTP Type
julia
ChannelwiseTP{T}(in1_ls, in2_ls, out_ls, instructions)

e3nn TensorProduct in uvu mode with one weight per channel and instruction: channel u of the first input couples only to channel u of the output. Slots have degrees in1_ls, in2_ls and out_ls; instructions lists (in1 slot, in2 slot, out slot, path weight), 1-based. The coupling tensor of an instruction is path weight · e3nn_wigner_3j(l1, l2, l3), stored as its nonzero entries.

PureMLIP.Tensors.tp_edge_add! Function
julia
tp_edge_add!(M, tp::ChannelwiseTP, x, Y, w) -> M

Adds the message of one edge to M (C × K_out): M[u, k] += Σ_p w[u, p] Σ_{i,j} pw_p C_p[i, j, k] x[u, i] Y[j], with x (C × K_in1) the sender features, Y (K_in2) the edge attributes and w (C × n_instructions) the weights.

As an einsum: ein"up,ui,j,pijk->uk"(w, x, Y, Cpw), with u the channel, p the instruction and i, j, k the components of x, Y and M; Cpw[p, i, j, k] is the dense form of the stored entries (zero outside the slots of instruction p).

PureMLIP.Tensors.tp_edge_pullback_add! Function
julia
tp_edge_pullback_add!(dx, dY, dw, tp::ChannelwiseTP, dM, x, Y, w; need_dx = true) -> nothing

Adds the vector-Jacobian products of tp_edge_add! with the cotangent dM to dx, dY and dw. With need_dx = false, dx is neither read nor written.

As einsums, with Cpw and the labels of tp_edge_add!: dx += ein"up,uk,pijk,j->ui"(w, dM, Cpw, Y), dY += ein"uk,up,ui,pijk->j"(dM, w, x, Cpw) and dw += ein"uk,ui,pijk,j->up"(dM, x, Cpw, Y).

PureMLIP.Tensors.E3nnLinear Type
julia
E3nnLinear{T}(weight, in_ls, out_ls, instructions, C_in, C_out)

e3nn Linear between slots of degrees in_ls and out_ls, C_in and C_out channels per slot. instructions lists (input slot, output slot, path weight), 1-based, in weight order; block p of weight is the torch [C_in, C_out] row-major segment p. Instructions sharing an output slot add up; an output slot without an instruction is zero, and an input slot without one is ignored.

PureMLIP.Tensors.linear! Function
julia
linear!(y, lin::E3nnLinear, x) -> y

y[w, k_out, i] = Σ_p pw_p Σ_u W_p[u, w] x[u, k_in, i] over the instructions p that map the input slot holding component k_in to the output slot holding k_out, with matching m. Overwrites y.

As an einsum: ein"puw,uki,pkq->wqi"(W, x, P), with W[p, u, w] in torch block order, u the input channel, w the output channel, p the instruction, k and q the input and output components and i the node; P[p, k, q] = pw_p where k and q are the same component m of the input and output slot of p, else zero (the matrix product is done per slot instead of with a dense P).

linear_pullback!(dx, lin::E3nnLinear, dy) -> dx

The vector-Jacobian product of linear! with the cotangent dy. Overwrites dx.

As an einsum: ein"puw,wqi,pkq->uki"(W, dy, P), with the labels of linear!.

PureMLIP.Tensors.SpeciesLinear Type
julia
SpeciesLinear{T}(weight, ls, instructions, C_in, n_species, C_out)

e3nn FullyConnectedTensorProduct of node features (slots of degrees ls) with a one-hot species vector: a linear map per species. instructions lists (input slot, output slot, path weight), 1-based; block p of weight is the torch [C_in, n_species, C_out] row-major segment p. c[p] = pw · (1 / sqrt(2l+1)), the path weight times e3nn's (l, 0, l) coupling; this product order reproduces e3nn's folded constants bit for bit.

source
PureMLIP.Tensors.species_linear! Function
julia
species_linear!(y, sl::SpeciesLinear, x, species) -> y

y[w, k, i] = c_p Σ_u W_p[u, species[i], w] x[u, k, i] for each instruction p, with k over the components of its slots. Overwrites y.

As an einsum: ein"pusw,is,uki,pkq->wqi"(W, onehot, x, P), with W[p, u, s, w] in torch block order, u the input channel, w the output channel, p the instruction, s the species, k and q the input and output components and i the node; onehot[i, s] = (s == species[i]) and P[p, k, q] = c_p where k and q are the same component m of the input and output slot of p, else zero (the matrix product is done per slot).

PureMLIP.Tensors.Contraction Type
julia
Contraction{T}(l, U1, U2, U3, Wmax, W0, W1)

One output irrep l (2l + 1 components) of a MACE symmetric contraction of correlation 3. U1, U2, U3 are the stored U_matrix_1..3 buffers in torch index order, with a leading m index of length 2l + 1 when l > 0 and none when l = 0; Wmax, W0, W1 are weights_max, weights.0, weights.1 in torch order [n_species, K, C]. The U arrays are kept as coordinate lists of their nonzero entries, ((m, w, x, i, k), value) for U3, with m = 1 when l = 0; the weights are kept as [C, K, n_species] so the channel index is innermost.

PureMLIP.Tensors.SymmetricContraction Type
julia
SymmetricContraction{T}(contractions)

The contractions of one MACE product block, in output order. Every contraction has the same channel count C, ell count L and species count. The output B has C × K_out entries per node, K_out = Σ (2l + 1), with the components of contraction j following those of j - 1.

PureMLIP.Tensors.symmetric_contraction! Function
julia
symmetric_contraction!(B, sc, X, species, scratch) -> B

MACE symmetric contraction of correlation 3. X is C × L × n (channel, e3nn ell index l² + m, node), species the 1-based species index of each node, B is C × K_out × n. For contraction ct of order l, with s = species[a] and the U and W of ct:

julia
C2[c, m, w, x] = Σ_k U2[m, w, x, k] W0[s, k, c] + Σ_{i,k} U3[m, w, x, i, k] Wmax[s, k, c] X[c, i, a]
C1[c, m, w]    = Σ_k U1[m, w, k] W1[s, k, c] + Σ_x C2[c, m, w, x] X[c, x, a]
B[c, o + m, a] = Σ_w C1[c, m, w] X[c, w, a]

where o is the number of components of the contractions before ct. scratch holds at least symmetric_contraction_scratch_size(sc) elements of the type of X.

As einsums, with z[a, s] = (s == species[a]), s the species, k the coupling-tensor component and m, w, x, i the indices of the U arrays (m is 1 for l = 0): B[c, m, a] is the sum of ein"mwk,skc,as,cwa->cma"(U1, W1, z, X), ein"mwxk,skc,as,cxa,cwa->cma"(U2, W0, z, X, X) and ein"mwxik,skc,as,cia,cxa,cwa->cma"(U3, Wmax, z, X, X, X). The U arrays are stored as nonzero entries.

source
PureMLIP.Tensors.symmetric_contraction_pullback! Function
julia
symmetric_contraction_pullback!(dX, sc, dB, X, species, scratch) -> dX

Overwrites dX with Σ dB .* ∂B/∂X for B of symmetric_contraction! at X. C2 and C1 are recomputed per node in scratch.

As an einsum, dX is the sum, over each X factor of each of the three einsums of symmetric_contraction!, of that einsum with the factor dropped, dB[c, m, a] (labels cma) as an extra operand, and the factor's own labels (cwa, cxa or cia) as the output.

symmetric_contraction_scratch_size(sc) -> Int

Length of the scratch vector that symmetric_contraction! and symmetric_contraction_pullback! need: the per-node C2 and C1 buffers of the largest contraction.
