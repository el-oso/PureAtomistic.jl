Equivariant math ​

PureMLIP provides the rotation-equivariant building blocks of MACE in pure Julia: real spherical harmonics, real Clebsch-Gordan coefficients, real Wigner matrices, and the conversion to the conventions used by e3nn.

All degrees up to lmax are stored in one vector of length (lmax + 1)^2. The degree-l block is contiguous, ordered   , and sits at the one-based position

which is sh_index(l, m); sh_length(lmax) gives the total length.

Coupling coefficients and Wigner matrices ​

spherical_harmonics!(Y, v, lmax) -> Y

Fill Y with the real spherical harmonics Y_lm(v / ‖v‖) for 0 ≤ l ≤ lmax, -l ≤ m ≤ l, orthonormal on the unit sphere with z as the polar axis and no Condon-Shortley phase. Y[firstindex(Y) - 1 + sh_index(l, m)] holds Y_lm. v has three entries read as x, y, z.

clebsch_gordan_complex(l1, m1, l2, m2, l3, m3) -> Float64

Condon-Shortley Clebsch-Gordan coefficient ⟨l1 m1 l2 m2 | l3 m3⟩ for integer l, by the Racah closed form with Float64 factorials. Returns 0.0 when m1 + m2 ≠ m3, when any |m| > l, or when l1, l2, l3 violate the triangle inequality.

PureMLIP.Equivariant.real_clebsch_gordan Function
julia
real_clebsch_gordan(l1, l2, l3) -> Array{Float64,3}

Real coupling tensor C[a, b, c] of shape (2l1+1, 2l2+1, 2l3+1) for the real spherical harmonics of spherical_harmonics!, indices ordered m = -l..l, normalized to unit Frobenius norm. It is Σ conj(U1[a,m1]) conj(U2[b,m2]) U3[c,m3] ⟨l1 m1 l2 m2 | l3 m3⟩ / sqrt(2 l3 + 1) with U_l the complex-to-real unitary, and is real when l1 + l2 + l3 is even.

Invariance under rotation, with D_l = wigner_D(l, R): Σ_abc C[a,b,c] D1[a,i] D2[b,j] D3[c,k] = C[i,j,k].

Throws ArgumentError unless |l1-l2| ≤ l3 ≤ l1+l2 and l1+l2+l3 is even.

source
PureMLIP.Equivariant.wigner_D Function
julia
wigner_D(l, R) -> Matrix{Float64}

Real Wigner matrix D of size (2l+1, 2l+1) for the rotation R (3×3, R'R = I, det R = 1, each to 1e-12), defined by Y_l(R v) = D * Y_l(v) for every v, where Y_l is the length-2l+1 block (m = -l..l) of spherical_harmonics!. D is orthogonal and wigner_D(l, R1 * R2) = wigner_D(l, R1) * wigner_D(l, R2).

Computed as D[i, j] = ∫ Y_i(R u) Y_j(u) dΩ (the harmonics are orthonormal) by Gauss-Legendre quadrature in cos θ (l + 1 nodes) times uniform φ (2l + 1 points), which is exact for the degree-2l integrand up to rounding.

source

e3nn_spherical_harmonics!(Y, v, lmax) -> Y

Fill Y (length sh_length(lmax)) with e3nn's spherical harmonics of v / ‖v‖ (normalize=True, normalization="component"), l-major in e3nn's component order: sqrt(4π) · Y_tb(v3, v1, v2) with Y_tb the harmonics of spherical_harmonics!.

PureMLIP.Equivariant.e3nn_basis_change Function
julia
e3nn_basis_change(l) -> Matrix{Float64}

Orthogonal matrix M of size (2l+1, 2l+1) with Y_e3nn,l = sqrt(4π) · M · Y_l, where Y_l is the degree-l block of spherical_harmonics!. Rows index e3nn components 0..2l, columns the native m = -l..l. It is wigner_D(l, R) for the rotation R: v ↦ (v3, v1, v2).

PureMLIP.Equivariant.e3nn_wigner_3j Function
julia
e3nn_wigner_3j(l1, l2, l3) -> Array{Float64,3}

e3nn's wigner_3j(l1, l2, l3): the unit-norm coupling tensor of shape (2l1+1, 2l2+1, 2l3+1) indexed by e3nn components. It is s · Σ M1[a,a'] M2[b,b'] M3[c,c'] C[a',b',c'] with C = real_clebsch_gordan(l1, l2, l3), Mi = e3nn_basis_change(li) and s = (-1)^((l1+l2-l3)/2). Entries with magnitude below 1e-13 are set to zero.

Throws ArgumentError unless |l1-l2| ≤ l3 ≤ l1+l2 and l1+l2+l3 is even.
